# نواة — النموذج الاستثماري

هذا النطاق يحل محل طلب بناء النظام التشغيلي السابق. التطبيق ثابت بالكامل، ببيانات مولدة محلياً وبدون خادم تطبيق أو API أو قاعدة بيانات أو تسجيل دخول. جميع التغييرات في ذاكرة المتصفح وتعود للبداية بعد تحديث الصفحة.

## البنية
- `dist/index.html`: نقطة الدخول العربية RTL.
- `dist/styles.css`: نظام التصميم والاستجابة والطباعة.
- `dist/data.js`: 572 وحدة وبيانات العقود والتحصيل والصيانة المحلية.
- `dist/ui.js`: عناصر الواجهة والأيقونات والتنسيق.
- `dist/pages.js`: صفحات الإدارة والتفاصيل والعرض الاستثماري.
- `dist/app.js`: التنقل وحالة العرض والنماذج والإجراءات التجريبية.

## التنقل
مسارات Hash تعمل في استضافة ثابتة: الرئيسية، النظرة العامة، المباني وتفاصيلها، الوحدات وتفاصيلها، رحلة التأجير، طلبات الإيجار وتفاصيلها، المستأجرون وTenant 360، العقود، الدفعات، الصيانة وتفاصيلها، التقارير، دورة الوحدة، القيمة المضافة، خارطة التطوير.

## رحلة العرض (3 دقائق)
حجم المشروع → المشكلة التشغيلية → لوحة الإدارة → المباني والوحدات → التأجير → المستأجر والعقد → التحصيل → الصيانة → التقارير → القيمة → التطوير. يوجد وضع عرض موجه للتنقل بهذه الخطوات.

## التفاعل
بحث وفلاتر وترقيم صفحات، تغيير وضع العرض للمباني، طلب إيجار جديد، اعتماد وحجز وعقد ودفعة وتسليم كتغييرات محلية مترابطة، ملف المستأجر، تسجيل دفعة، بلاغ صيانة وتعيين فني وتقدم التنفيذ، فلاتر انتهاء العقود، تصدير تقرير محلي وطباعة، إعادة ضبط العرض. جميع البيانات تعريفية مصطنعة.

## قرارات الاتساق
329 مؤجرة و243 شاغرة = 572. الصيانة المفتوحة على وحدات مؤجرة لا تغيّر إشغالها تلقائياً. حالة «تحت الصيانة» للوحدة تعني أنها غير قابلة للتأجير ويمكن تجربتها على وحدة شاغرة. أعداد المباني والتقارير محسوبة من نفس بيانات الوحدات.
