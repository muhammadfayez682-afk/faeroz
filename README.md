# إمدادات الجودة — Investor Demo

نموذج استثماري تفاعلي عربي RTL لإدارة وتشغيل مشروع حي النواة – حارة الفيروز، مع برنامج تجديد المباني والانتقال المؤقت للسكان.

## ما الذي يعمل؟
- لوحة إدارة محسوبة من 572 وحدة، منها 329 مؤجرة و243 شاغرة تعاقدياً.
- المباني والوحدات، البحث والفلاتر والترقيم، الملفات التفصيلية.
- رحلة تأجير تفاعلية: مراجعة → اعتماد → حجز → عقد → دفعة → تسليم.
- Tenant 360 والعقود والتحصيل الجزئي والصيانة ومتابعة تنفيذ البلاغات.
- تقارير مبسطة وتصدير CSV وطباعة، دورة حياة الوحدة والقيمة التجارية وخارطة التطوير.
- برنامج التجديد: خطط 12 مبنى، 46 أسرة متأثرة، تخصيص السكن المؤقت، تأكيد الانتقال، اعتماد الأعمال وفحص الجودة والعودة.
- تحديث العدادات وسجل المستأجر ومخزون الوحدات بعد الإجراءات المحلية.
- توزيع الـ243 وحدة غير المؤجرة: 150 جاهزة، 45 محجوزة، و48 تحت الصيانة. الجاهزة تشمل 38 وحدة جاهزة للسكن المؤقت؛ والمحجوزة تشمل 16 وحدة مخصصة للأسر. يظل العدد المؤجر تعاقدياً 329 وحدة.
- عرض استثماري موجه من زر «ابدأ العرض».
- خدمات السكان: رابط QR مستقل لكل وحدة، أربع خدمات، صورة اختيارية، أولوية، إرسال وتتبع الطلب، ولوحة مسؤول لإدارة التنفيذ.

## طبيعة النموذج
ملفات HTML/CSS/JavaScript ثابتة فقط. لا يوجد Backend أو API أو Database أو Authentication أو تكامل خارجي داخل التطبيق. الخط محفوظ محلياً بترخيصه. جميع البيانات مصطنعة؛ طلبات السكان والصور المصغرة محفوظة في LocalStorage، وبقية التغييرات في ذاكرة المتصفح وتُعاد بعد التحديث. تاريخ العرض المرجعي: 15 سبتمبر 2026؛ تستخدم طلبات السكان الوقت الفعلي للمتصفح.

## تشغيله
انشر محتويات `dist` على أي استضافة ملفات ثابتة أو افتحها عبر معاينة ملفات محلية. رابط البداية `/`، وبرنامج التجديد متاح في `/renovation/` وأيضاً `/#/renovation`. التنقل بين باقي الصفحات يستخدم Hash ولا يحتاج خادم تطبيق.

للمعاينة المحلية عند توفر Python:
```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```
ثم افتح `http://127.0.0.1:4173/`. هذا لخدمة الملفات الثابتة محلياً فقط.

التحقق بدون تثبيت حزم:
```sh
npm run check
```

## اتساق برنامج التجديد
«31 أسرة تم نقلها» عدد تراكمي: 17 عادت + 14 تقيم مؤقتاً. توجد 15 أسرة بانتظار النقل، منها أسرتان لهما تخصيص. للحفاظ على 38 وحدة جاهزة كما طلب في لوحة الإدارة، يتكون مخزون العرض من **54 وحدة = 14 مستخدمة + 38 جاهزة + 2 محجوزة**. الأرقام 40/31/7/2 في الطلب كانت مثالاً؛ لا يمكن جمعها مع 38 جاهزة و31 انتقالاً تراكمياً في لقطة بيانات واحدة دون تناقض.

المخزون المؤقت جزء من 243 وحدة غير مؤجرة تعاقدياً؛ عقود الأسر تبقى على وحداتها الأصلية، لذا لا يتغير عدد العقود أو الإشغال التعاقدي عند النقل المؤقت. تمنع رحلة التأجير اختيار وحدة مخصصة للسكن المؤقت. بعد العودة، تتحرر الوحدة ويمكن إعادتها لمخزون التأجير من صفحتها.

إنجاز البرنامج 24% موزون بنطاق العمل: 20% وزن لكل من A01 وA02، و6% لكل مبنى لاحق. التقدم الابتدائي 68% و52% للمبنيين الجاريين. تنتقل الأعمال إلى فحص الجودة قبل السماح بالعودة. تعكس المخططات المرحلة الأبعد ضمن التنفيذ المرحلي؛ تفاصيل كل أسرة تظهر في جدول السكان.

## حدود العرض
المراحل المستقبلية في خارطة التطوير توضيحية فقط. تمديد العقد محاكاة لتاريخ النهاية، والإخلاء مخطط إرشادي، ولا يصدر هذا النموذج عقوداً قانونية أو ينفذ تحصيلاً حقيقياً. متوسط إغلاق الصيانة المعروض قيمة توضيحية معلّمة بذلك. صور طلبات السكان محلية فقط؛ لا توجد مراسلات أو مدفوعات خارجية.

## تجربة خدمات السكان

1. افتح `/faeroz/service/?unit=A02-105` مباشرة؛ يُستنتج المبنى والوحدة من الرابط دون تسجيل دخول أو إدخال أرقام.
2. اختر «طلب صيانة»، نوع المشكلة، الوصف والأولوية، ثم أرسل. الصورة اختيارية، تقبل JPG/PNG/WebP حتى 8 MB وتُصغّر محلياً قبل الحفظ.
3. يظهر رقم طلب جديد مثل MNT-1045، وزر لمتابعة مراحله الست.
4. افتح `/#/resident-requests` في المتصفح نفسه: تظهر الطلبات والصور والأولوية، ويمكن تعيين الفني ثم بدء العمل والإصلاح والإغلاق. تتحدث صفحة المتابعة في التبويب الآخر تلقائياً.
5. «تجربة خدمات السكان / QR» في لوحة المسؤول أو «QR خدمات السكان» في تفاصيل أي وحدة يتيح تنزيل رمز حقيقي بصيغة SVG.

يعمل الحفظ تحت المفتاح `nawa.resident-tickets.v1` على **الأصل نفسه والمتصفح نفسه**. لا توجد مزامنة بين الأجهزة. رابط localhost يُفتح على الكمبيوتر المحلي فقط؛ لا يصل إليه هاتف آخر. عند نشر الملفات، يُولّد QR باستخدام عنوان الاستضافة الحالي. إعداد صلاحية استضافة الموقع منفصل عن التطبيق الذي لا يحتوي على تسجيل دخول.

يمكن إعادة بيانات التجربة من «خيارات العرض ← إعادة ضبط البيانات»؛ يشمل ذلك طلبات السكان المحلية. إذا امتلأت مساحة التخزين، يظهر خطأ ويظل النموذج قابلاً للتعديل. إعادة توليد صفحة الخدمات المشتركة بعد تغيير قالب HTML: `npm run generate:services`.


## GitHub Pages

مجلد النشر هو `docs` تحت `/faeroz/`. بوابة المستأجر صفحة واحدة: `docs/service/index.html`، تقرأ `unit` من query string. مثال: `/faeroz/service/?unit=A02-105`. لا توجد صفحات HTML منفصلة للوحدات. جميع الأصول نسبية إلى المجلد، وروابط QR تحافظ على بادئة الموقع. زر «تجربة بوابة المستأجر» في لوحة التحكم يفتح `./service/?unit=A02-105`. عند غياب الوحدة تظهر رسالة طلب مسح QR، ولا تظهر بيانات وحدة افتراضية.
