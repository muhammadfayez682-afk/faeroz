# نواة — Investor Demo

نموذج استثماري تفاعلي عربي RTL لإدارة وتشغيل مشروع حي النواة – حارة الفيروز، مع برنامج تجديد المباني والانتقال المؤقت للسكان.

## ما الذي يعمل؟
- لوحة إدارة محسوبة من 572 وحدة، منها 329 مؤجرة و243 شاغرة تعاقدياً.
- المباني والوحدات، البحث والفلاتر والترقيم، الملفات التفصيلية.
- رحلة تأجير تفاعلية: مراجعة → اعتماد → حجز → عقد → دفعة → تسليم.
- Tenant 360 والعقود والتحصيل الجزئي والصيانة ومتابعة تنفيذ البلاغات.
- تقارير مبسطة وتصدير CSV وطباعة، دورة حياة الوحدة والقيمة التجارية وخارطة التطوير.
- برنامج التجديد: خطط 12 مبنى، 46 أسرة متأثرة، تخصيص السكن المؤقت، تأكيد الانتقال، اعتماد الأعمال وفحص الجودة والعودة.
- تحديث العدادات وسجل المستأجر ومخزون الوحدات بعد الإجراءات المحلية.
- عرض استثماري موجه من زر «ابدأ العرض».

## طبيعة النموذج
ملفات HTML/CSS/JavaScript ثابتة فقط. لا يوجد Backend أو API أو Database أو Authentication أو تكامل خارجي. الخط محفوظ محلياً بترخيصه. جميع البيانات مصطنعة؛ التغييرات في ذاكرة المتصفح فقط وتُعاد بعد التحديث. تاريخ العرض المرجعي: 15 سبتمبر 2026.

## تشغيله
انشر محتويات `dist` على أي استضافة ملفات ثابتة أو افتحها عبر معاينة ملفات محلية. رابط البداية `/`، وبرنامج التجديد متاح في `/renovation/` وأيضاً `/#/renovation`. التنقل بين باقي الصفحات يستخدم Hash ولا يحتاج خادم تطبيق.

للمعاينة المحلية عند توفر Python:
```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```
ثم افتح `http://127.0.0.1:4173/`. هذا لخدمة الملفات الثابتة محلياً فقط.

التحقق بدون تثبيت حزم:
```sh
node scripts/verify.mjs
```

## اتساق برنامج التجديد
«31 أسرة تم نقلها» عدد تراكمي: 17 عادت + 14 تقيم مؤقتاً. توجد 15 أسرة بانتظار النقل، منها أسرتان لهما تخصيص. للحفاظ على 38 وحدة جاهزة كما طلب في لوحة الإدارة، يتكون مخزون العرض من **54 وحدة = 14 مستخدمة + 38 جاهزة + 2 محجوزة**. الأرقام 40/31/7/2 في الطلب كانت مثالاً؛ لا يمكن جمعها مع 38 جاهزة و31 انتقالاً تراكمياً في لقطة بيانات واحدة دون تناقض.

المخزون المؤقت جزء من 243 وحدة غير مؤجرة تعاقدياً؛ عقود الأسر تبقى على وحداتها الأصلية، لذا لا يتغير عدد العقود أو الإشغال التعاقدي عند النقل المؤقت. تمنع رحلة التأجير اختيار وحدة مخصصة للسكن المؤقت. بعد العودة، تتحرر الوحدة ويمكن إعادتها لمخزون التأجير من صفحتها.

إنجاز البرنامج 24% موزون بنطاق العمل: 20% وزن لكل من A01 وA02، و6% لكل مبنى لاحق. التقدم الابتدائي 68% و52% للمبنيين الجاريين. تنتقل الأعمال إلى فحص الجودة قبل السماح بالعودة. تعكس المخططات المرحلة الأبعد ضمن التنفيذ المرحلي؛ تفاصيل كل أسرة تظهر في جدول السكان.
